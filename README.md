# Напиток дня — iOS-приложение

Нативное приложение на SwiftUI: при открытии показывает «напиток дня» (один и тот же до полуночи), кнопка «Другой» выдаёт случайный коктейль без повторов, кнопка «Открыть рецепт» ведёт на страницу коктейля на ru.inshaker.com. Всего 21 рецепт на русском.

Что умеет:

- «Напиток дня» — выбор по дате, стабильный в течение дня;
- «Другой» — случайный коктейль, пока не кончатся все 21, повторов подряд нет;
- «Копировать» — рецепт текстом в буфер обмена;
- «Поделиться» — системное меню Share;
- тактильный отклик (haptics), тёмная тема, Dynamic Type, iPad;
- работает офлайн, интернет нужен только для перехода на сайт с рецептом.

## Вариант 1. Mac + Xcode (рекомендую)

Нужен любой Mac с macOS 13+ и Xcode 15+ (бесплатно из App Store). iPhone — с iOS 16+.

1. **Откройте проект.** Двойной клик по `DrinkOfTheDay.xcodeproj` (или `open DrinkOfTheDay.xcodeproj` в терминале).
2. **Добавьте Apple ID.** Xcode → Settings… → Accounts → «+» → Apple ID. Бесплатного аккаунта достаточно.
3. **Выберите команду.** В левом списке выберите проект `DrinkOfTheDay` → target `DrinkOfTheDay` → вкладка **Signing & Capabilities** → Team: ваш Apple ID. Если Xcode ругается на занятый Bundle Identifier — замените `com.example.drinkoftheday` на что-то уникальное, например `ru.вашлогин.drinkoftheday`.
4. **Подключите iPhone** кабелем, нажмите «Доверять» на телефоне. На iOS 16+ включите режим разработчика: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить → перезагрузить телефон.
5. **Запустите.** В верхней панели Xcode выберите ваш iPhone вместо симулятора → **⌘R**.
6. **Доверьте разработчику** на iPhone: Настройки → Основные → VPN и управление устройством → Developer App → «Доверять».

Готово — иконка «Напиток дня» появится на домашнем экране.

**Ограничения бесплатного Apple ID:** подпись живёт **7 дней**, затем приложение перестанет открываться — подключите телефон к Mac и снова ⌘R. Одновременно можно держать до 3 своих приложений. Платный Apple Developer Program ($99/год) снимает 7-дневный лимит и даёт TestFlight для установки без кабеля.

## Вариант 2. Без Mac, с Windows — 3 шага до `.ipa`

Готовый архив репозитория лежит рядом: `../drink-of-the-day-ios-repo.zip`. Внутри проект и уже настроенный workflow, который соберёт `.ipa` сам и положит его в **Releases** — оттуда файл скачивается без входа в GitHub.

1. **Создайте репозиторий.** [github.com/new](https://github.com/new) → имя, например `drink-of-the-day` → **Public** → Create repository.
2. **Загрузите файлы.** Распакуйте `drink-of-the-day-ios-repo.zip` и на странице репозитория нажмите «uploading an existing file», затем перетащите **всё содержимое** распакованной папки (включая скрытую `.github`) → Commit changes. Сборка запустится сама.
   Если `.github` не перенеслась: Add file → Create new file → в поле имени введите `.github/workflows/build-ios.yml` → вставьте содержимое одноимённого файла из архива → Commit.
3. **Заберите `.ipa`.** Вкладка **Actions** → дождитесь зелёной галочки «Build IPA (unsigned)» (3–5 минут) → справа **Releases** → «Напиток дня — сборка N» → скачайте `DrinkOfTheDay-unsigned.ipa`.
4. **Установите Sideloadly** с [sideloadly.io](https://sideloadly.io). Для работы с iPhone на Windows также нужен iTunes из Microsoft Store (драйверы устройств).
5. **Подключите iPhone**, перетащите `.ipa` в Sideloadly, введите Apple ID. Пароль лучше создать отдельный: appleid.apple.com → Безопасность → Пароли приложений.
6. **Start** → дождитесь «Done». На iPhone: Настройки → Основные → VPN и управление устройством → доверять профилю.
7. **Обновляйте подпись раз в 7 дней.** В Sideloadly нажмите Refresh, либо поставьте AltStore/AltServer — он продлевает подпись автоматически по Wi-Fi, пока компьютер включён.

Если Apple ID с двухфакторной аутентификацией не принимается — используйте именно «пароль приложения», а не обычный пароль.

## Если проект не открывается

Ручной проект `project.pbxproj` написан без Xcode, поэтому в редких случаях Xcode может его не принять. Два простых обхода:

- **XcodeGen:** установите `brew install xcodegen`, затем в папке `ios/` выполните `xcodegen generate` — проект пересоберётся из `project.yml`.
- **Вручную за 2 минуты:** Xcode → File → New → Project → iOS → App, имя `DrinkOfTheDay`, интерфейс SwiftUI, язык Swift. Удалите созданные `App.swift` и `ContentView.swift`, перетащите в проект 4 файла из `ios/DrinkOfTheDay/` (`DrinkOfTheDayApp.swift`, `ContentView.swift`, `Cocktail.swift`, `Theme.swift`) и папку `Assets.xcassets`. Дальше — шаги 2–6 из варианта 1.

## Структура

```
ios/
├── DrinkOfTheDay.xcodeproj/          # проект Xcode (открывать этот файл)
│   ├── project.pbxproj
│   └── xcshareddata/xcschemes/       # схема для ⌘R и для CI
├── DrinkOfTheDay/
│   ├── DrinkOfTheDayApp.swift        # точка входа
│   ├── ContentView.swift             # экран, карточка, логика выбора
│   ├── Cocktail.swift                # модель + 21 рецепт
│   ├── Theme.swift                   # цвета, кнопки, фон
│   └── Assets.xcassets/              # иконка 1024×1024, AccentColor
├── project.yml                       # альтернатива через XcodeGen
└── .github/workflows/build-ios.yml   # сборка .ipa на GitHub Actions
```

## Что менять

- **Название на экране «Домой»** — `INFOPLIST_KEY_CFBundleDisplayName` в настройках target (сейчас «Напиток дня»).
- **Идентификатор** — `PRODUCT_BUNDLE_IDENTIFIER`.
- **Иконка** — замените `Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` (1024×1024, без прозрачности).
- **Рецепты** — массив `Cocktail.all` в `Cocktail.swift`. У каждого коктейля есть `slug` — часть адреса `https://ru.inshaker.com/cocktails/<slug>`. Ссылка на конкретный рецепт должна существовать, иначе кнопка приведёт на 404.

## Честное примечание

Проект собирался в среде без macOS, поэтому саму компиляцию Xcode я не прогонял. Проверено автоматически: структура `project.pbxproj` (25 объектов, все ссылки целы, секции на месте), 21 уникальный коктейль без дублей slug, корректность JSON ассетов, иконка 1024×1024 в RGB. Синтаксис Swift выверен вручную — если Xcode найдёт мелочь, она будет в одном-двух местах и правится за минуту.
